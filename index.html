📲 Pasang Aplikasi ke Perangkat

Game ini mendukung teknologi PWA (Progressive Web App) sehingga dapat diinstal seperti aplikasi asli dan bisa dimainkan secara offline tanpa internet!

Langkah Pemasangan Cepat:
  • Google Chrome / Edge (Laptop/PC): Klik ikon [⊕ Install] di pojok kanan bilah alamat (URL bar), atau klik menu titik tiga [⋮] ➔ "Instal Aplikasi".
  • Android (Chrome): Tekan menu titik tiga [⋮] di pojok atas ➔ pilih "Instal Aplikasi" atau "Tambahkan ke Layar Utama".
  • iPhone / iPad (Safari): Tekan ikon Share [⎙] di bawah layar ➔ pilih "Add to Home Screen" (Tambah ke Layar Utama).

📖 Panduan Fasilitasi Guru

Simulasi OS Windows Realistis

Game ini sekarang mensimulasikan lingkungan File Explorer yang realistis. Siswa WAJIB menggunakan Klik Kanan (Right-Click) menggunakan Mouse/Touchpad untuk memunculkan menu perintah seperti di OS Windows.

  • Klik Kanan pada File: Muncul opsi Cut, Copy, Rename, Delete.
  • Klik Kanan pada Folder: Muncul opsi Paste (jika ada file di-cut), dsb.
  • Klik Kanan pada Ruang Kosong (Warna Putih): Muncul opsi New Folder, Paste.
  • Untuk Rename/New Folder: Label akan berubah menjadi kotak ketik. Siswa harus mengetik nama dan menekan tombol Enter di keyboard.
